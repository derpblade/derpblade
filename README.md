## derpblade here 👋

Most of what I build is small and close to the metal: CLI tools in Rust, C shims for the places where an abstraction just gets in the way, and the occasional WebAssembly module that has to run somewhere it was never meant to fit. I spend a lot of time on startup latency, allocator behavior, and figuring out why a build takes 40 seconds when it should take 4. My side projects are mostly terminal UIs and shell scripts I will eventually rewrite in Rust.
